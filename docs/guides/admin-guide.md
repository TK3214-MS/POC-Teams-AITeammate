# AI Teammate 管理者ガイド

## 管理画面アクセス

管理画面は Teams タブアプリとして、または直接URLでアクセスできます。

## ダッシュボード

### 表示項目

- **ナレッジ総数**: テナント全体で蓄積されたナレッジエントリの合計
- **会議セッション数**: AI Teammateが参加した会議の合計
- **AI分析回数**: 実行された分析の合計回数
- **アクティブユーザー数**: 過去30日間にアクティブなユーザー数
- **カテゴリ別ナレッジ分布**: 暗黙知カテゴリごとの蓄積数
- **AI利用コスト**: トークン消費量と推定コスト

## エージェント設定

### 介入設定

| 設定 | 説明 | デフォルト |
| ------ | ------ | ----------- |
| 介入頻度 | low/medium/high | medium |
| 沈黙検知閾値 | 沈黙を検知するまでの秒数 | 15秒 |
| 最大介入回数/会議 | 1会議あたりの最大介入回数 | 20回 |
| プロアクティブ介入 | 能動的な介入の有効/無効 | 有効 |
| クールダウン | 介入間の最小間隔 | 60秒 |

### 質問生成設定

| 設定 | 説明 | デフォルト |
| ------ | ------ | ----------- |
| 有効カテゴリ | 生成する質問の種類 | 全5種類 |
| 最大質問数/介入 | 1回の介入で生成する最大質問数 | 3 |
| 最低優先度 | 投稿する質問の最低優先度 | Medium |

### データストア設定

| 設定 | 説明 | デフォルト |
| ------ | ------ | ----------- |
| プロバイダー | データ永続化先 | CosmosDB |
| RAG検索 | RAG検索の有効/無効 | 有効 |
| 最小関連度スコア | RAG結果の最小スコア | 0.7 |

### 言語設定

| 設定 | 説明 | デフォルト |
| ------ | ------ | ----------- |
| 自動検出 | 会話言語の自動検出 | 有効 |
| 優先言語 | デフォルト言語 | ja-JP |
| サポート言語 | 対応言語リスト | ja-JP, en-US |

### 会議フィルター

| 設定 | 説明 | デフォルト |
| ------ | ------ | ----------- |
| 全会議対象 | 全会議に参加するか | はい |
| 対象オーガナイザー | 特定のオーガナイザーのみ | 空（全員） |
| 除外パターン | 除外する会議名パターン | 空 |
| 最小参加者数 | 参加する最小人数 | 2 |

## ナレッジ管理

### ナレッジの検索・フィルター

- テキスト検索: タイトル・内容で全文検索
- カテゴリフィルター: 暗黙知カテゴリでフィルター
- ステータスフィルター: Draft/Confirmed/Edited/Rejected/Archived

### ナレッジの編集

1. 一覧からエントリを選択
2. タイトル・内容・カテゴリを編集
3. 保存ボタンで更新

### バルク操作

- エクスポート: CSV/JSON形式でダウンロード
- アーカイブ: 選択したエントリをアーカイブ
- 削除: 選択したエントリを削除（確認ダイアログあり）

## ユーザー管理

### 権限レベル

| レベル | 説明 |
| -------- | ------ |
| Admin | 全設定の変更、ユーザー管理、ナレッジの削除 |
| User | ナレッジの閲覧・編集、会議への参加 |
| Viewer | ナレッジの閲覧のみ |

## 監査ログ

全管理操作は監査ログに記録されます:

- 設定変更
- ナレッジの作成・編集・削除
- ユーザー権限の変更

監査ログは管理画面から閲覧可能です。
