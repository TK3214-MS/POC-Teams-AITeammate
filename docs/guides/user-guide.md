# AI Teammate ユーザーガイド

## AI Teammateとは

AI Teammateは、Teams会議にAIチームメイトとして参加し、会話をリアルタイムで分析して暗黙知を自動蓄積するボットです。

## 基本的な使い方

### 1. 会議への参加

現在のAI Teammateは、音声・映像の参加者として会議へ入室するボットではありません。会議チャットに追加されたアプリとして動作し、`join` コマンドで分析セッションを開始します。

#### 事前準備

AI TeammateがTeamsのアプリ一覧にない場合は、先に管理者が `TeamsAITeammate/ai-teammate-app.zip` をTeams管理センターの **Teamsアプリ > アプリを管理 > 新しいアプリをアップロード** から登録します。既存アプリを更新する場合も同じZIPをアップロードしてください。現在の会議Bot・サイドパネル対応パッケージはversion 1.0.4です。

1. Teamsで対象の会議を開きます。
2. 会議画面の **アプリ** から **AI Teammate** を追加します。**アプリ** が上部にない場合は **その他 (...) > アプリを追加** を開きます。
3. 会議チャットを開き、AI Teammateが利用可能になっていることを確認します。
4. 会議へ参加します。この時点では分析セッションも音声取得も開始されません。

アプリ更新後も表示されない場合は、対象会議から以前のAI Teammateを削除して追加し直すか、新しい予定済み会議で確認してください。その後Teamsを完全終了して再起動します。管理者はTeams管理センターのアプリ許可ポリシーでAI Teammateがブロックされていないことも確認します。

#### 分析を開始する

会議チャットでAI Teammateをメンションし、次のように送信します。

```text
@AI Teammate join
```

チャット欄に `join` だけを入力しても、グループチャットではボット宛てのメッセージとして配信されない場合があります。候補一覧から **AI Teammate** を選択し、メンション表示になっていることを確認してください。

正常に開始すると、次の応答が返ります。

```text
✅ 会議に参加しました。トランスクリプト分析を開始します。
セッションID: ...
```

応答を確認してから、次の順序で音声分析を開始します。

1. 会議画面の **アプリ** から **AI Teammate** のSidePanelを開きます。
2. SidePanelの接続状態が `Connected` になることを確認します。
3. マイクボタンを押し、ブラウザーまたはTeamsのマイク利用を許可します。
4. テスト発話を行い、文字起こしと分析結果がSidePanelに表示されることを確認します。
5. 会議チャットで `@AI Teammate status` を送信し、セッション状態を確認します。

現在の構成では、SidePanelを開いたユーザーの端末マイク音声をAzure AI Speechで文字起こしします。Teams標準の会議トランスクリプトや他の参加者の分離音声を自動取得する構成ではありません。最初のテストでは1人だけがマイク分析を開始してください。

### 2. コマンド

会議チャットで以下のコマンドが使えます:

| コマンド | 説明 |
| --------- | ------ |
| `@AI Teammate join` | 会議の分析セッションを開始 |
| `@AI Teammate status` | 現在の分析状態を表示 |
| `@AI Teammate summarize` | これまでの会話サマリーを表示 |
| `@AI Teammate ask 質問` | 蓄積されたナレッジに質問 |
| `@AI Teammate settings` | エージェント設定を変更 |
| `@AI Teammate leave` | 分析セッションを終了 |

### 3. 質問カード

AI Teammateが会話を分析し、追加質問が必要と判断した場合、Adaptive Cardとして質問を投稿します。

**回答方法:**

- 「回答する」ボタンをクリックして回答を入力
- 「スキップ」で質問をスキップ
- 「後で」で後回しにする

### 4. サイドパネル

`@AI Teammate join` の応答を確認した後にSidePanelを開き、マイクボタンから音声分析を開始します。`join` より先に開始すると、分析セッションが存在しないため文字起こしを保存できません。

会議中、SidePanelではリアルタイムで以下が確認できます:

- 検出されたトピック一覧
- 生成された質問のキュー
- 抽出された暗黙知候補
- 会話サマリー

### 5. ナレッジの確認

AI Teammateが抽出した暗黙知は、確認カードとして表示されます:

- 「確認」: ナレッジとして蓄積
- 「編集」: 内容を修正して蓄積
- 「却下」: 蓄積しない

## 暗黙知のカテゴリ

| カテゴリ | 説明 | 例 |
| --------- | ------ | ----- |
| 専門スキル | 個人の経験に基づく知識 | 「私の経験では...」 |
| 判断根拠 | 意思決定の背景 | 「この理由で選んだ」 |
| 未文書化プロセス | 暗黙の手順 | 「いつもこうしている」 |
| 教訓 | 過去の失敗/成功からの学び | 「前回の障害では...」 |
| 関係性知識 | チーム内の暗黙の関係 | 「○○さんに聞くと早い」 |
| 背景文脈 | ドメイン固有の知識 | 「顧客数が30%増加した」 |
| 文化規範 | チームの暗黙のルール | 「金曜日はデプロイしない」 |

## よくある質問

**Q: `@AI Teammate join` を送っても何も起こりません。**
A: 次の順番で確認してください。

1. AI Teammateが対象会議のアプリとして追加されているか
2. `join` だけでなく、候補から選択した `@AI Teammate` メンション付きで送信しているか
3. 個別チャットではなく、対象会議の会議チャットで送信しているか
4. Azure Container Appの `/healthz` がHTTP 200を返すか
5. Azure Botのメッセージングエンドポイントがデプロイ先を向いているか
6. TeamsへインストールしたアプリのBot IDが、Azure Bot/EntraアプリのApplication (client) IDと一致しているか
7. ログに `Parsed command: join` があるのに応答がない場合、`AADSTS7000215` や `invalid_client` が出ていないか。出ている場合は、Botのclient secret valueを再発行し、Container Appが参照するsecretを更新して再起動します。secret IDは使用できません。

それでも応答しない場合は、Container Appsのログで受信を確認します。

```bash
az containerapp logs show \
  --name <container-app-name> \
  --resource-group <resource-group> \
  --follow
```

メッセージ受信時には `Parsed command: join` が記録されます。ログ自体が出ない場合はTeamsアプリ、Bot ID、またはAzure Botのメッセージングエンドポイントを確認してください。

Botの受信ルートも確認できます。

```bash
curl --request POST \
  --header 'Content-Type: application/json' \
  --data '{}' \
  --output /dev/null \
  --write-out '%{http_code}\n' \
  'https://<container-app-fqdn>/api/messages'
```

- `400` または `401`: 受信ルートは存在します。Bot ID、認証情報、Teamsアプリの追加状態を確認してください。
- `404`: Agentの受信ルートがデプロイされていません。`app.MapDefaultAgentEndpoints()` を含む最新版をContainer Appへデプロイしてください。

**Q: AI Teammateが会議の参加者一覧に表示されません。**
A: 現在の実装はCalling/Media Botではないため、音声・映像の参加者一覧には表示されません。`join` は会議チャット上の分析セッションを開始するコマンドです。

**Q: AI Teammateは会議の内容を外部に送信しますか？**
A: いいえ。テナント内のAzureリソースでのみ処理され、テナント外にデータは送信されません。

**Q: 特定の会議だけ対象にできますか？**
A: はい。管理画面の「会議フィルター」設定で、対象のオーガナイザーや除外パターンを設定できます。

**Q: 蓄積されたナレッジを削除できますか？**
A: はい。管理画面のナレッジ管理から個別またはバルクで削除できます。
