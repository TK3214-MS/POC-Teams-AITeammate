## 指示

以下の観点から、追加で議論すべき議題を提案してください。
提案は{{$language}}で行ってください。

1. **議論不足のトピック**: 言及されたが十分に深掘りされていない重要な論点
2. **関連する未議論事項**: 現在の議題に関連するが、まだ取り上げられていない重要な事項
3. **過去のナレッジベースからの提案**: 過去の会議や知識ベースから関連する未解決事項

JSON配列で出力してください:
```json
[
  {
    "title": "議題タイトル",
    "rationale": "この議題を提案する理由",
    "priority": "Critical|High|Medium|Low",
    "relatedTopicIds": ["関連するトピックID"]
  }
]
```

提案のルール:
1. 会議の目的と時間を考慮し、優先度の高い議題を上位に配置する
2. 既に十分に議論されたトピックの再議論は提案しない
3. 具体的で実行可能な議題のみ提案する
4. JSON以外のテキストは出力しないでください
