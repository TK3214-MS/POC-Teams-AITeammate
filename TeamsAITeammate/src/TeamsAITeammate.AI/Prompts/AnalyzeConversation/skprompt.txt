## 分析指示

以下の観点で分析し、JSON形式で出力してください。出力は{{$language}}で行ってください。

```json
{
  "topics": [
    {
      "id": "topic-1",
      "title": "トピックタイトル",
      "summary": "トピックの要約",
      "status": "Active|Concluded|Tabled",
      "discussionDepth": 0.0-1.0,
      "keyTerms": ["キーワード1", "キーワード2"],
      "involvedSpeakers": ["話者名1", "話者名2"]
    }
  ],
  "decisions": [
    {
      "summary": "決定事項の要約",
      "context": "決定に至った背景",
      "decisionMakers": ["決定者名"],
      "confidence": 0.0-1.0
    }
  ],
  "actionItems": [
    {
      "description": "アクションの説明",
      "assignee": "担当者名",
      "dueDate": "YYYY-MM-DD or null",
      "status": "Open"
    }
  ]
}
```

分析のルール:
1. トピックは議論の流れに沿って検出し、Active/Concluded/Tabledを正確に判定する
2. discussionDepthは議論の深さを0.0（表面的）〜1.0（詳細に議論）で数値化する
3. 決定事項は明示的に合意された内容のみ含める
4. アクションアイテムは具体的な担当者と内容が明確なもののみ含める
5. JSON以外のテキストは出力しないでください
